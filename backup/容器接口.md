# 1. BeanFactory

## （1）什么是BeanFactory

>什么是BeanFactory
>- 它是ApplicationContext的父接口
>- 它是Spring的核心容器，主要的ApplicationContext都【借助】或【组合】了它的功能

```java
ConfigurableApplicationContext configurableApplicationContext = SpringApplication.run(XXX.class, args);
```

SpringBoot启动类的`run()`方法返回的就是一种`ApplicationContext`。

## （2）BeanFactory可以干什么

- 表面看，只有`getBean()`这个功能
- 实际上，控制反转、基本的依赖注入，直至Bean的生命周期的各种功能，都由它的实现类提供（`DefaultListableBeanFactory`）

## ApplicationContext在BeanFactory的基础上扩展了哪些功能？

扩展的功能主要体现在其额外实现的四个接口上
- MessageSource：国际化能力
- ResourcePatternResolver：根据通配符获取类路径下资源
- ApplicationEventPublisher：获取配置信息
- EnvironmentCapable：事件发布（可以用于事件解耦）
