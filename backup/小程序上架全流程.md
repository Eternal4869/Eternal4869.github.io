小程序上架并非简单的“上传代码”，而是一个涉及**资质合规、技术开发、平台审核**的系统工程。由于微信和支付宝两大主流平台的流程与规范差异较大，建议你先确定目标平台，再按对应流程推进。

### 📱 微信小程序上架全流程

微信小程序的完整上架周期通常需要**4-8周**，核心环节包括备案、开发、审核三步。

| 阶段 | 关键步骤 | 核心要点 |
| :--- | :--- | :--- |
| **1. 账号与备案** | 注册账号（微信公众平台） | 个人主体功能受限（如无法使用支付），企业需营业执照 |
| | 小程序备案 | 强制要求，主体信息必须与账号一致；周期约7-14个工作日 |
| **2. 开发与测试** | 开发工具配置 | 使用官方开发者工具，填写AppID，配置服务器域名（需HTTPS） |
| | 功能开发 | 页面层级不超过10层；单个JS文件建议2000行内；图片建议使用WebP格式 |
| | 真机测试 | 覆盖iOS/Android不同机型，重点测弱网环境、接口响应速度 |
| **3. 提交审核** | 上传代码 | 代码包不超过2MB，填写版本号与备注 |
| | 类目与资质 | 根据功能选对类目（如AI问答需"深度合成"类目），提交相应资质 |
| | 等待审核 | 周期1-7个工作日；常见驳回原因：功能不完整、含敏感词、页面白屏等 |
| **4. 发布与运维** | 正式发布 | 审核通过后，建议先灰度发布（如10%用户），观察1天无异常再全量 |
| | 持续运维 | 监控启动耗时（建议<1.5s）、接口成功率（>99%），建立版本回滚机制 |

> **避坑提示**：个人主体无法开通微信支付。若小程序涉及Web-View，必须完成业务域名验证并上传校验文件。

### 💙 支付宝小程序上架全流程

支付宝小程序的审核把合规与用户体验放在第一位，尤其看重功能的可用性。

| 阶段 | 关键步骤 | 核心要点 |
| :--- | :--- | :--- |
| **1. 账号与准入** | 注册认证 | 个人或企业均可，经营类目需对应经营主体（个人/企业） |
| | 类目与资质 | 不同行业有严格资质要求（如餐饮、医疗），名称不得使用宽泛词汇 |
| **2. 开发与测试** | 技术规范 | 强制HTTPS，SSL证书有效期不得少于30天 |
| | 功能自测 | **严禁**出现白屏、闪退、按钮无响应等情况；不得包含VConsole等调试入口 |
| **3. 提交审核** | 上传与提审 | 在开放平台上传版本，提供完整测试账号与流程说明 |
| | 关键规范 | 用户授权必须有效；支付收单必须接入"JSAPI支付"；跳转须由用户主动触发 |
| **4. 发布与运营** | 灰度/上架 | 可设置体验版或灰度测试，审核通过后正式上架 |

> **避坑提示**：支付宝对**交互缺陷**是"零容忍"的，提交前务必反复验证，确保所有按钮、页面跳转、登录流程都无报错。

开发前，建议先去对应平台的开放社区或规则中心，查阅最新的运营规范和技术文档，因为具体类目要求和接口权限可能会随时调整。
